Toolbox.

A small rack of utilities, hosted in-house. Every tool below runs entirely in your browser — files and data never leave your machine.

№Tool
  • 01 BentoPDF → The complete PDF workbench — merge, split, compress, convert, rotate, sign and redact, processed locally via WebAssembly. PDFWASMOffline
  • 02 CyberChef → The cyber Swiss-army knife — encode, decode, hash, compress, parse and analyse data with hundreds of chainable operations. EncodingCryptoForensics
  • 03 Excalidraw → A virtual whiteboard with a hand-drawn feel — sketch diagrams, wireframes and ideas, then export to PNG or SVG. WhiteboardDiagramsSVG
  • 04 draw.io → Structured diagramming — flowcharts, UML, network topologies, org charts and mockups with a full shape library. DiagramsUMLFlowcharts
  • 05 IT Tools → A drawer of small developer utilities — token and UUID generators, JWT parser, base converters, QR codes, cron helper and more. GeneratorsConvertersDev
  • 06 JSON Crack → Paste JSON, YAML, CSV or XML and see it as an interactive graph — explore, search and export the structure. JSONVisualizationGraph
  • 07 drawDB → Design database schemas visually — tables, relations and constraints, exported as SQL for MySQL, Postgres, SQLite and more. DatabaseSchemaSQL
  • 08 Mermaid Live → Write Mermaid text, get diagrams — flowcharts, sequence and state diagrams, ready to paste into READMEs and docs. DiagramsText-to-chartDocs
  • 09 VERT → Convert files between formats — images, audio and documents, processed locally with WebAssembly. No size limits. ConverterWASMFiles
▮ 9 tools mounted 100% client-side processing
